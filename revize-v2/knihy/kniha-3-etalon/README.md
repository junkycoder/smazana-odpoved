# Kniha třetí — ETALON

> Třetí díl pětidílné ságy. Stav: **2. redakční verze** — kauzální přepis, předmluva, 6 kapitol, Klíč, Kolík, Úřední údaje.

## Zadání dílu

| | |
|---|---|
| **Otázka** | Proč Odpověď chybí? → obrací se na **Kdo ji doplní?** |
| **Fyzický cíl** | Etalon Core / Lhář — je dutý (sál mrtvých Odkazů, střeží absenci) |
| **Cena za selhání — NASTANE** | Cvok zajat; vytěžen modul `214-K-07` s indexem provenience a interní servisní identitou |
| **Šifra** | Obraz-prompt (recept se otiskne textem, obraz nikdy; nastražené díry) |
| **Dílčí poučení šifry** | Co chybí, poznáš podle tvaru díry. |

## Co tahle kniha dělá

- Textura: **lesk/povrch** — delší hladká souvětí, zrak, odrazy; město jmenuje a eviduje všechno (inverze bezejmenné vesnice).
- Sirotek vstupuje do města **jako klon** (peněženky = jméno; „schovává se šumem"); deadpan obdiv města (teplá voda) s pomalu prosakující cenou.
- Do studia nejde náhodou: aktivně překlápí rozpis podle veřejné reference a krade lokální papírové auditní náhledy promptů; žádné pixely nevysílá.
- Satira zblízka: pasení chudí se žebracími peněženkami bez klíčů, kult „ověřeno" (razítko ≠ pravda), klonová kariéra, Tvář dostává text foneticky, byrokracie prázdna.
- Spor elit sirotek aktivně vyvolá chybnou evidencí zmetků: „to už jsme jednou dovolili" v HR jazyce; **nedokončená, špatně evidovaná věc**.
- **Cena nastane:** sirotek se otočí od Core za bednou — **refrén ② „Nenech ho ležet"**; Parťák vytvoří slepý bod skartace. Modul `214-K-07` neobsahuje epizody ani větu, ale vazby kdo/kdy/odkud a servisní podpis. Core jej přijme jako interní diagnostický etalon.
- **Dutina** (kap. 5): sál Odkazů — stovky skel, všechna mrtvá a němá; pán sbírá vyluxované obaly a střeží tvar vlastní prázdnoty. Zaťukání bez ozvěny.
- **Díra** (kap. 6): překryté auditní tisky → táž kapsa prázdna → tvar = sirotkova čmáranice; Lhář dojde ke stejnému výsledku a nebe vyhlásí hon. Provenience modulu dává oběma stranám adresu: dílna 18 / Archivní uzel Brno.
- **Playbackové díry: tři, všechny po Lháři** (chodba studia · sál Odkazů · poslední brána). Vzniknou až při pozdním nahrávání celé ságy v K5; obyčejné zapomenutí se za díru nevydává.

## Postavy zavedené v knize 3

- **Tvář** — celebrita-maska z ukolébavek; text po slabikách do ucha; „Já nevím, co je za tím slovem dál."
- **Lhář** — nepopsatelný, uměle symetrický, vyschlý a přesto září; hádka o rozpočet na úklid; „účetní rozhodnutí nemá dělat skutečnost".
- **Parťák** — klon s hrdostí na kariéru svého pána; naučí sirotka překlopit rozpis a při skartaci oslepí kameru.
- **Neznámý odesílatel** — jednorázovou veřejnou referencí navede klonovu legendu ke studiím; původ reference se splácí v K4.
