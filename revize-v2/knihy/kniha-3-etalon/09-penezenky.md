# Úřední údaje

*(Opis. Ve městě visí peněženky všude, tak jsem vybral dvě, co vedle sebe visely nejradši.)*

První patří nadaci. Nadace patří jádru, ale to se nepíše; píše se tohle, zlatým písmem na černém skle u vchodu do studií:

```
┌──────────────────────────────────────────┐
│   OFICIÁLNÍ PENĚŽENKA                    │
│   NADACE ČISTÝ ZÍTŘEK                    │
│   pomáháme, kde je to vidět              │
│                                          │
│   [QR]  bc1q-DOPLNIT-ADRESU-NADACE      │
│                                          │
│   Výroční zpráva ověřena.                │
└──────────────────────────────────────────┘
```

Druhá visí na tyčce nad miskou na Dolním okruhu, sedmé stanoviště od mýta. Patří člověku, který u ní sedí. Klíče k ní drží správa, aby se výtěžek nezneužil. Co mu z ní pustí, je věc postupu.

```
┌──────────────────────────────────────────┐
│   VEŘEJNÁ SBÍRKA — STANOVIŠTĚ 07         │
│   transparentní pomoc v nouzi            │
│                                          │
│   [QR]  bc1q-DOPLNIT-ADRESU-OKRUH07     │
│                                          │
│   Každý dar dohledatelný.                │
└──────────────────────────────────────────┘
```

Obě jsou veřejné. Obě jsou dohledatelné. Obě jsou ověřené. Víc na nich není — a to, co na nich není, už umíš hledat sám.
