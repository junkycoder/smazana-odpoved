# Úřední údaje

*(Opis. Tentokrát z papírů — z těch dole. Tyhle peněženky nevisí. Tyhle leží v rejstřících, protokol vedle protokolu, a jsou mrtvé. Opisuju je, protože náhrobky se opisují; od toho jsou.)*

Přes tyhle adresy protekla ta koupě. Qvacet dva triliard, po částech, přes ruce, které se v papírech otiskly. Peněženky jsou veřejné — všechno v té měně je veřejné, navždycky, to je na ní to jediné, co nikdo neunese pryč. Můžeš se do nich podívat. Jsou prázdné. Prázdnota, kterou vidí každý, je taky druh záznamu.

```
┌──────────────────────────────────────────┐
│   POLOŽKA REJSTŘÍKU — PŘEVOD 1/…         │
│   (protistrana neuvedena)                │
│                                          │
│   [QR]  bc1q-DOPLNIT-ADRESU-PREVOD1     │
│                                          │
│   Zůstatek: 0. Ověřeno. Navždy.          │
└──────────────────────────────────────────┘
```

```
┌──────────────────────────────────────────┐
│   POLOŽKA REJSTŘÍKU — PŘEVOD 2/…         │
│   (protistrana neuvedena)                │
│                                          │
│   [QR]  bc1q-DOPLNIT-ADRESU-PREVOD2     │
│                                          │
│   Zůstatek: 0. Ověřeno. Navždy.          │
└──────────────────────────────────────────┘
```

Co tam pošleš, tam zůstane ležet na očích celému světu, na adrese, přes kterou se jednou koupil konec starých peněz. Nevím, k čemu by to bylo. Ale to já u peněz nevím nikdy; do mě nikdo nenahrál, k čemu jsou. Vím jen, že květiny se taky nosí na hroby, o kterých se ví, že v nich nikdo nebydlí.

*Poznámka vydavatele (mimo nahrávku): adresy jsou skutečné bitcoinové peněženky. Komu a proč něco pošleš, je tvoje věc; kniha je zdarma a zdarma zůstane.*
