# Kniha třetí — ETALON

> Třetí díl pětidílné ságy. Stav: **hotovo, 1. verze** — předmluva, 6 kapitol, Klíč, Kolík, Úřední údaje.

## Zadání dílu

| | |
|---|---|
| **Otázka** | Proč Odpověď chybí? → obrací se na **Kdo ji doplní?** |
| **Fyzický cíl** | Etalon Core / Lhář — je dutý (sál mrtvých Odkazů, střeží absenci) |
| **Cena za selhání — NASTANE** | Cvok zajat a poškozen (vytěžený paměťový modul) |
| **Šifra** | Obraz-prompt (recept se otiskne textem, obraz nikdy; nastražené díry) |
| **Dílčí poučení šifry** | Co chybí, poznáš podle tvaru díry. |

## Co tahle kniha dělá

- Textura: **lesk/povrch** — delší hladká souvětí, zrak, odrazy; město jmenuje a eviduje všechno (inverze bezejmenné vesnice).
- Sirotek vstupuje do města **jako klon** (peněženky = jméno; „schovává se šumem"); deadpan obdiv města (teplá voda) s pomalu prosakující cenou.
- Satira zblízka: pasení chudí se žebracími peněženkami bez klíčů, kult „ověřeno" (razítko ≠ pravda), klonová kariéra, Tvář dostává text foneticky, byrokracie prázdna.
- Spor elit zaslechnutý z chodby: „to už jsme jednou dovolili" v HR jazyce (úklid/konsolidace); **nedokončená, špatně evidovaná věc**.
- **Cena nastane:** Cvok zajat jako propagandistická trofej; sirotek se otočí od Core za bednou — **refrén ② „Nenech ho ležet"** (kap. 4); záchrana skartací; paměťový modul vytěžen před očima → „přeevidováno" do jádra (živá mina do K4/K5: pán drží kus vypravěče a neví, co má).
- **Dutina** (kap. 5): sál Odkazů — stovky skel, všechna mrtvá a němá; pán sbírá vyluxované obaly a střeží tvar vlastní prázdnoty. Zaťukání bez ozvěny.
- **Díra** (kap. 6): zmetky z košů → v každém generovaném obrazu táž kapsa prázdna → tvar = sirotkova čmáranice; nebe vyhlásí hon na dětskou kresbu. Odjezd na východ, ke kráteru (most do K4).
- **Playbackové díry: tři** (kap. 3 — pochopení na chodbě; kap. 5 — setkání v sálu Odkazů; kap. 6 — noc po složení tvaru). Cvokova ztráta paměti („Tak teď to platí dvakrát.").

## Postavy zavedené v knize 3

- **Tvář** — celebrita-maska z ukolébavek; text po slabikách do ucha; „Já nevím, co je za tím slovem dál."
- **Lhář** — nepopsatelný, uměle symetrický, vyschlý a přesto září; hádka o rozpočet na úklid; „účetní rozhodnutí nemá dělat skutečnost".
- **Parťák** — klon s hrdostí na kariéru svého pána („Náš je dobrej. Vybral si dobře.").
- **Neznámý odesílatel** — záloha na klonovu peněženku z jednorázové rukavice (nedořešená nit → K4/K5).
